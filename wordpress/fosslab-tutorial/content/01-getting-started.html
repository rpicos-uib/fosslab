All the programs run on the course server {{server}}. You see them on your computer through a remote desktop (X2Go, recommended) or through SSH with X forwarding.

1. Log in

Option A: X2Go (a full desktop, best for layout work)

  1. Install the X2Go client from wiki.x2go.org (Windows, macOS, Linux).
  2. New session: Host {{server}}, Login your user name, Session type XFCE.
  3. Connect. The first time, you are asked to change your password.

Option B: SSH with X forwarding (Linux, or macOS with XQuartz)

$ ssh -X your_user@{{server}}

Every window then opens on your own screen. This is fine for schematics; for large layouts X2Go is much faster.

2. Start the Library Manager

In the XFCE menu: Development > FOSSLab Library Manager. Or, in a terminal:

$ fosslab

The first time, it creates your workspace, the folder ~/fosslab, with one empty library called work. The Library Manager is where everything starts: you create, find and open all your designs here, and run the checks on them. This is how it looks once you have built the op-amp of this tutorial:

3. The window, part by part

PartWhat it is for
1MenusFile: new library, new cell, open a terminal in the workspace. Cell: everything you can do with the selected cell (new view, copy, rename, delete, run a flow, see its results). Tools: start xschem, KLayout or Magic on their own, run the self-test. Help: this tutorial and a quick guide.
2WorkspaceThe folder that holds all your work, ~/fosslab. Keep your designs inside it: your teacher can look at it to help you.
3LibrariesYours under Workspace (here work and opamp_tut). Below, the IHP PDK libraries, greyed because they are read only: sg13g2_pr (transistors, resistors, capacitors), sg13g2_stdcell (logic gates), devices (sources, ground, pins), sg13g2_tests (IHP's example testbenches). Click a library to see its cells.
4CellsThe cells of the selected library: the circuits (opamp), their models (opamp_va) and their testbenches (tb_…). Type in filter to find one in a long list.
5Views of each cellA dot under Sch, Sym, Lay when the cell has a schematic, a symbol, a layout. Here, opamp has all three; the testbenches only a schematic.
6ResultsA tick when the last simulation, DRC, LVS or extraction (PEX) of the cell passed, a red cross when it failed, nothing if it was never run. Here, opamp is DRC and LVS clean and extracted, and the three testbenches were simulated.
7ViewsThe files of the selected cell: the ones you edit (black) and the ones the flows make from them (grey: netlists, extracted circuits). Double-click one to open it in the right program.
8OpenOpen the schematic, symbol or layout of the selected cell, or browse its hierarchy (the blocks inside it).
9RunRun a flow on the selected cell: simulate it (a testbench), check its layout (DRC), compare layout and schematic (LVS), extract the layout's parasitics (PEX). A window shows the progress and the result.
10Sim. EnvironmentFor a testbench: set variables and outputs, then sweep corners or run Monte Carlo. Chapters 9 to 11.
11Status lineThe selected cell, and a summary of its last results (here: 0 DRC violations, LVS match, 70 devices and 424 parasitic capacitors extracted). When nothing is selected, a hint.

Right-click a library, a cell or a view to see everything you can do with it: the same as the Cell menu 1, closer to hand. Double-clicking a cell 4 opens its main view (the schematic, or the layout if there is no schematic).

Your own workspace starts with only the library work, empty. You will build opamp_tut in the next chapters, and see the dots and ticks appear one by one.

In xschem itself: select an instance and press e to descend into its schematic, i into its symbol, Ctrl+e to go back up. The Hierarchy browser shows the whole tree at once, with the views and verification status of every block.

5. Try it: the self-test

In the Library Manager, Tools > Run self-test. In about a minute it builds an inverter in a temporary folder and runs the whole flow on it with the real IHP process: simulation, DRC, LVS, extraction and post-layout simulation. Every line should say PASS.

Flows:
  [PASS] ngspice simulation: simulation finished, 1 .raw file(s); tpd = 19.0 ps
  [PASS] DRC (IHP deck): DRC clean: 0 violations
  [PASS] LVS (IHP deck): LVS clean: netlists match
  [PASS] PEX (Magic): extracted 2 devices and 5 parasitic capacitors
  [PASS] post-layout simulation: tpd = 21.4 ps (schematic: 19.0 ps)

Notice the last line: the extracted wire capacitances make the inverter about 12 % slower than the schematic predicts. This is what post-layout simulation is for.

Your teacher can see your workspace (read only), to help you and to follow your progress. Keep your design work inside ~/fosslab.
