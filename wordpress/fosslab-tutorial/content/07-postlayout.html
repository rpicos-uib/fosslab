The layout adds wire capacitances that the schematic does not have. Post-layout simulation tells what they cost.

1. Extract

FOSSLab > Extract parasitics (PEX) or the PEX button. Magic reads the layout and writes opamp_pex.spice: the transistors (one per finger: 70 for the reference layout) and every capacitance between wires and to substrate (424 here). It appears as the view Extracted + parasitics.

2. Simulate with the extracted view

Select the testbench tb_opamp_ac, right-click > Run > Simulate with extracted views... and tick opamp. The testbench is not changed: FOSSLab replaces the op-amp's schematic by its extracted netlist in the simulation, connecting the pins by name (the extractor orders them its own way). From the command line: fosslab sim opamp_tut tb_opamp_ac --extracted opamp.

To use the extracted view in corners or Monte Carlo too, choose it in the Simulation Environment, tab Views (chapter 4): Extracted (post-layout, from PEX) for opamp. Best in a setup of its own (Save as..., e.g. postlayout), so the schematic setup stays as it is.

DC results do not change (wires add no DC path); everything that depends on capacitance does. The extra capacitance at the first stage's output and at OUT lowers the second pole: less bandwidth and phase margin. All specifications are still met.
