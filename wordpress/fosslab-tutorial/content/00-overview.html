This tutorial takes one circuit, a two-stage CMOS operational amplifier (the classic design of Allen & Holberg, CMOS Analog Circuit Design), through the complete analog design flow: schematic, simulation, a behavioural model, layout, verification and post-layout simulation, then process corners and Monte Carlo. Everything is done with free and open-source software and a real, public 130 nm process: IHP SG13G2.

Libraries, cells and views

Designs are organised in libraries, cells and views. A library holds cells (an op-amp, a current mirror, a testbench). Each cell has several views, each one a different description of the same thing, edited with its own program:

The FOSSLab Library Manager shows libraries, cells and views side by side and opens every view in the right program, already set up for the IHP process. From inside the schematic editor and the layout editor, a FOSSLab menu jumps to the other views of the same cell: from a schematic to its layout and back, to the whole design hierarchy, to the verification results.

The flow, step by step

  1. Schematic capture of the op-amp, with input/output pins, and its symbol.
  2. A testbench: a separate cell that uses the op-amp's symbol, adds supplies and sources, and tells the simulator what to do. Simulate; compare with the specifications; go back to the schematic until they are met.
  3. A Verilog-A model of the op-amp, for fast system-level simulations, checked against the transistor-level circuit.
  4. The layout, with the process's parameterised cells (PCells).
  5. DRC (design rule check): is it manufacturable? LVS (layout versus schematic): is it the same circuit?
  6. Parasitic extraction and post-layout simulation: how much do the wires change the performance?
  7. Corners and Monte Carlo: does it still work when the process, the supply and the temperature move?
Everything runs on the course server, inside one container image (IIC-OSIC-TOOLS) that holds every program and the IHP PDK, so all students use exactly the same versions. You only need a remote-desktop client: see the next chapter.
